GNC · Trajectory Optimization

Europa EDL — MPC & Convex Optimization

AAE 590 Capstone · Purdue University · Spring 2026

Full Entry, Descent & Landing simulation for a Europa lander. Entry controlled via Pontryagin Maximum Principle bang-bang optimal control; descent & landing via Second-Order Cone Programming (SOCP) with receding-horizon Model Predictive Control and nonlinear RK4 dynamics propagation.

Key Results Touchdown 409.1 kg @ 2.001 m/s · MPC lateral error 1.68 m · Avg SOCP solve 899 ms
Python · CVXPY · SciPy · MATLAB
ML · NLP · Generative AI

CADformer — Natural Language to CAD

ECE 595 Term Project · Purdue University · Fall 2025

Five-stage NL-to-CadQuery pipeline combining DECINT-style interleaved decomposition with Gorilla-inspired BM25 retrieval-augmented code generation. Benchmarked on CADBench across three difficulty levels against direct-prompting and chain-of-thought baselines.

Key Result 86.1% execution success rate vs. 77.8% (DIRECT) and 69.4% (CoT)
Python · Azure OpenAI · CadQuery · BM25
Spacecraft Structures

Europa Lander Structural Sizing

AAE 590 Capstone · Purdue University · Spring 2026

Structural sizing of Ti-6Al-4V landing legs for a Europa lander. Parametric MATLAB sweep over leg geometry, wall thickness, and taper ratio to minimize mass while satisfying buckling and yield margins per NASA GEVS / Falcon Heavy environments.

Key Result 619.2 N/leg axial load · Positive margins at all critical load cases
MATLAB · Ti-6Al-4V · NASA GEVS
Autonomy · Robotics

Voice-Controlled Autonomous Duckiebot

ECE 595 · Purdue University · Spring 2026

Voice-controlled lane-following robot using Azure STT/TTS, roslibpy over ROS bridge WebSocket, and custom OpenCV lane detection. Implemented real-time motor control with threading safety and TTS feedback-loop prevention.

Highlight Full voice command pipeline: speech → intent → lane-following control → spoken feedback
Python · ROS · OpenCV · Azure Cognitive Services
Astrodynamics · Mission Design

Earth-to-Mars Low-Thrust Transfer (LinCov)

AAE 590 · Stochastic & Optimal Control · Spring 2026

Linear Covariance (LinCov) analysis and Monte Carlo validation of a low-thrust Earth-to-Mars trajectory. Propagated state uncertainty through heliocentric transfer, comparing navigation error growth between LinCov and full nonlinear Monte Carlo.

Highlight LinCov σ envelopes matched Monte Carlo to within 3% across all trajectory phases
MATLAB · LinCov · Monte Carlo · STMs
